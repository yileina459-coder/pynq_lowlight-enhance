# 校赛一页材料：低延迟视觉增强终端

> 参赛方向：2026 全国大学生嵌入式芯片与系统设计竞赛 · FPGA 创新设计赛道 · AMD 自主选题
> 平台：PYNQ-Z2（XC7Z020）　工具：Vivado / Vitis HLS 2026.1
> 状态：算法内核已逐位验证 + 已综合；端到端真机画面待 HDMI 采集卡到货（预计 10/22）

## 一句话

一台**不经过帧缓冲**、端到端延迟只有一行的实时图像增强终端，面向低视力人群的阅读辅助与低照度场景。

## 1 问题与用户

- 用户：低视力人群（我国视力残疾约 1700 万）、需要在暗光/逆光下阅读的老年人
- 痛点：市售电子助视器价格高；通用手机/PC 方案从采集到显示通常 100~300 ms，**延迟大导致眩晕、疲劳**
- 关键判断：这类设备的核心指标不是帧率，而是**端到端延迟**

## 2 方案

```
HDMI 源 ─ dvi2rgb ─ v_vid_in_axi4s ─ pixel_pack ─┐
                                                 │
                       enhance_0（自研 HLS 核）  │  局部对比 → 色调曲线
                                                 │  → 二值/反色 → 分屏
HDMI 屏 ◄ rgb2dvi ◄ v_axi4s_vid_out ◄ pixel_unpack
```

- **零帧缓存**：像素边走边算，延迟约一行（而非一帧）
- **参数化**：59 bit 配置（清晰度/拐点/双段增益/阈值/反色/单色/分屏位置）由 PS 实时下发
- **分屏对比**在核内用现成的列计数器实现，零额外资源
- 整数全定点，硬件与 numpy 参考模型**逐位一致**，可做 0 容差回归

## 3 已完成的证据

| 项目 | 方法 | 结果 | 证据 |
|---|---|---|---|
| 逐位正确性 | 独立编写的 C++ 黄金模型，两种配置（对比度+分屏 / 色调+二值+反色+单色） | **各 9216 拍 0 误差** | `src/hls/enhance/tb_enhance.cpp` |
| 独立复核 | numpy 黄金模型，恒等预设必须逐位等于输入 | **通过** | `sim/enhance/golden_enhance.py` |
| 综合结果 | Vitis HLS 2026.1，`xc7z020clg400-1`，7 ns 约束 | **II=1**；BRAM 3 / DSP 2 / FF 2168 / LUT 1657（3%）；估计 **Fmax 194.59 MHz** | `build/hls/enhance/` |
| 视觉验证 | 7 个预设（清晰度/阅读/夜间/反色/二值/分屏） | 暗光页平均亮度 27 → 150，文字可辨 | `sim/enhance/golden_enhance.py --grid` |
| 既有硬件证据 | DMA 通路整帧传输、与黄金参考比对 | **0/2764800 通道不一致**；15.8 ms/帧 | `board/dma_sobel/` |

时钟预算：视频通路 142.86 MHz，核估计 194.59 MHz，余量约 27%。
