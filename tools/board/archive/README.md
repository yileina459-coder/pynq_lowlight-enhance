# archive - 被合并掉的两个窗口

2026-10-23 把图片窗口和视频窗口合并成了一个：`upload_panel.ps1`（双击根目录的
`上传到开发板.bat`）。这里保留的是合并前的两个脚本。

| 文件 | 原来的窗口 | 合并后 |
|---|---|---|
| `video_gui.ps1` | "视频播放（自动选挡位）" | 统一面板，选到视频时显示视频选项 |
| `upload_gui.ps1` | "图片上传到开发板" | 统一面板，选到图片时显示图片选项 |

**为什么合并**：两个窗口做的是同一件事（选文件 → 传板子 → 切画面），差别只在选项，用户却要
先想"我该点哪个"。统一面板按扩展名（GIF/WebP 再数帧数）判断类型，只显示相关选项。

**保留了它们当年踩过的两个坑**，因为都很容易重犯：

1. `-Tone ''` 在命令行传不进去（PowerShell 丢掉空串再报"缺少参数"）——所以面板用 `-NoTone`
   开关表示"不处理"。
2. `$args` 是自动变量，在按钮事件里它是鼠标事件参数；把它当哈希表 splat 出去，`-Fps` 会收到
   `MouseEventArgs`。面板里改名为 `$playArgs`。
