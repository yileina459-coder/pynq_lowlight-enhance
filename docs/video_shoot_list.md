## 二、OBS 配置（录制前 5 分钟）

1. 场景里只留 **视频采集设备** 一个源，采集卡分辨率设为 `1920×1080`、帧率 `30`。
2. 预览里点一下空白处**取消红色选中框**，鼠标移出画面。
3. 设置 → 输出：录像格式 `mp4`，编码器 `x264`，码率控制 `CQP=20`，预设 `veryfast`。
4. 设置 → 视频：基础与输出分辨率都 `1920×1080`，FPS `30`。
5. 关掉微信/QQ 弹窗与系统通知（Windows 专注助手 → 仅闹钟）。
6. 确认窗口标题、桌面图标里没有校名。

## 四、解说（可选，10 句以内）

> 这是一个面向低照度图像观察的低延迟视觉增强终端，运行在 PYNQ-Z2 上。
> 整条增强链都在可编程逻辑的像素流里完成，不经过帧缓冲，延迟只有 21 个像素时钟，约 147 纳秒。
> 主机把图片上传到板端，处理结果经 HDMI 输出，再由采集卡回采，在 OBS 里看到的就是最终画面。
> 这里依次切换十档预设：清晰度增强、提亮、暗部压暗、去饱和、反色、二值化，以及左右分屏对比。
> 数字正确性由另一条 AXI-DMA 通路保证：与 NumPy 黄金模型逐位一致，差异为零。
> 同一块板子上，Sobel 算法在 PL 上比 ARM+NumPy 快约 196 倍，输出同样逐位一致。

## 五、合成与转码

```powershell
# 1) 合并分段（按文件名顺序）
ffmpeg -f concat -safe 0 -i list.txt -c copy merged.mp4

# 2) 统一转成 H.264 + yuv420p，去掉超长部分
ffmpeg -i merged.mp4 -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 20 -movflags +faststart -an 演示视频.mp4
```

`list.txt` 每行一个分段：

```
file 'seg01.mp4'
file 'seg02.mp4'
```

**检查**：

```powershell
ffprobe -v error -show_entries format=duration,size -show_entries stream=codec_name,width,height,r_frame_rate -of default=nw=1 演示视频.mp4
```

- `codec_name=h264`、`duration` ≤ 180、`size` ≤ 300 MB。
- 若超时，优先压第 6 段（十档轮流）每档 4 s → 3 s。
